# vLLM 源码阅读笔记

从一次文本生成请求出发，逐步理解 vLLM 的输入处理、调度、KV cache 和模型执行。

## 阅读目录

- [00 从离线生成入口开始](<00 从离线生成入口开始.md>)：从最小离线生成示例和 `LLM.generate()` 入手，梳理采样参数、返回值及入口层的职责。
- [01 请求准备与参数对齐](<01 请求准备与参数对齐.md>)：梳理 `_run_completion()` 的分工、逐请求参数整理、长度校验与共享对象引用。
- [02 逐条提交请求与生成器](<02 逐条提交请求与生成器.md>)：追踪生成器的执行时机、请求 ID、`FINAL_ONLY` 和提交失败后的异常清理。

## 源码基准

笔记基于 [vLLM 提交 e2d2680417](https://github.com/vllm-project/vllm/tree/e2d2680417432b80986a36d456e3d79173ee1a45)，文中链接固定到对应源码版本。
