# vLLM 源码阅读笔记

从一次文本生成请求出发，逐步理解 vLLM 的输入处理、调度、KV cache 和模型执行。

## 阅读目录

- [00 从离线生成入口开始](<00 从离线生成入口开始.md>)：从最小离线生成示例和 `LLM.generate()` 入手，梳理采样参数、返回值及入口层的职责。
- [01 请求准备与参数对齐](<01 请求准备与参数对齐.md>)：梳理 `_run_completion()` 的分工、逐请求参数整理、长度校验与共享对象引用。
- [02 逐条提交请求与生成器](<02 逐条提交请求与生成器.md>)：追踪生成器的执行时机、请求 ID、`FINAL_ONLY` 和提交失败后的异常清理。
- [03 引擎循环与结果收集](<03 引擎循环与结果收集.md>)：理解 `_run_engine()` 的循环条件、已完成结果的累积，以及按请求 ID 恢复返回顺序。
- [04 引擎输出与用户结果](<04 引擎输出与用户结果.md>)：进入 `LLMEngine.step()`，区分核心内部结果、输出后处理、用户结果和停止通知。
- [05 FINAL_ONLY 与请求状态](<05 FINAL_ONLY 与请求状态.md>)：追踪解码器怎样跨轮保存生成进度，以及 `FINAL_ONLY` 如何暂缓中间结果并构造最终输出。
- [06 同步多进程客户端与结果队列](<06 同步多进程客户端与结果队列.md>)：区分后台接收线程与调用线程，理解结果入队、同步等待和跨进程结果传递。
- [07 EngineCore 进程主循环与输入处理](<07 EngineCore 进程主循环与输入处理.md>)：进入核心进程，理解已有工作如何持续推进、何时等待输入，以及两侧输出队列的区别。
- [08 单步调度与模型执行](<08 单步调度与模型执行.md>)：连接调度安排、Future 等待、模型结果与请求状态更新，辨析调度 token 数和执行标志。
- [09 新 token 记录与停止检查](<09 新 token 记录与停止检查.md>)：追踪先追加 token 再检查停止的顺序，确认返回值二元组、停止原因与分支优先级。
- [10 请求 token 累积与长度限制](<10 请求 token 累积与长度限制.md>)：理解连续追加如何累积请求内容，区分总 token 数与生成 token 数及对应的长度限制。
- [11 调度计数与 token 预算](<11 调度计数与 token 预算.md>)：区分请求长度、输入计算进度与本轮共享预算，解释生成 token 与待处理位置的关系。
- [12 候选处理量与预算限制](<12 候选处理量与预算限制.md>)：推演进度差额、阈值和预算如何限制候选处理量，区分处理位置与新生成 token 数。

## 源码基准

笔记基于 [vLLM 提交 e2d2680417](https://github.com/vllm-project/vllm/tree/e2d2680417432b80986a36d456e3d79173ee1a45)，文中链接固定到对应源码版本。
